# DWIE dodatkowe rzeczy, których requirements.txt nie umie wyrazić:

#      pip install --ignore-requires-python -r requirements-namecheap-py39.txt
#
# 2. Łatka `from __future__ import annotations` na ZAINSTALOWANYM pakiecie
#    `garminconnect` (i `ua_generator`, dla pewności) — kod używa składni
#    `X | None` w adnotacjach typów, którą Python 3.9 ocenia eagerly (od 3.10
#    jest to leniwe) i wywraca się na niej `TypeError` przy imporcie. Bez tej
#    łatki `import garminconnect` w ogóle się nie uda:
#      find <venv>/lib/python3.9/site-packages/garminconnect -name '*.py' -exec sed -i '1i from __future__ import annotations' {} \;
#      find <venv>/lib/python3.9/site-packages/ua_generator   -name '*.py' -exec sed -i '1i from __future__ import annotations' {} \;
#
# Pełny runbook (skąd wziąć <venv>, jak sprawdzić że zadziałało) —
